Default Rate Analysis · By Risk Segment
Default Rate by LVR Band
The sharpest risk gradient in LMI portfolios. Each 5-point LVR step materially increases default probability.
Default Rate by Borrower Type
Investors show higher default rates than owner-occupiers — investment properties are more likely to be sold or defaulted on when cash flow deteriorates.
Default Rate by Property Type
Apartments and land carry higher default rates. Land loans lack income-generating capacity; apartments face oversupply risk that depresses recoveries.
Employment Risk · State vs National Benchmark
Default Rate by Employment Type
Self-employed borrowers carry the highest default risk — income volatility, irregular cash flows, and greater economic-cycle exposure. Contract workers sit between PAYG and self-employed.
